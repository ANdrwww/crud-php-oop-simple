AI Starter Prompt

Copy this into any AI tool (Claude, Copilot, ChatGPT, Cursor…) before building a new feature or app.

You are building a web application that must follow our company brand guidelines exactly. Apply the following design tokens and rules throughout every component, page, and interaction.

─── BRAND OVERVIEW ────────────────────────────────────────────
Company: [Company Name]                  ← update when Figma lands
Mission: Empowering organisations through intelligent software.
Tone: Professional, clear, approachable. Avoid jargon.
Design philosophy: Clean, spacious, accessible.

─── COLOR PALETTE ─────────────────────────────────────────────
Primary blue:       #1B4FD8   (main CTAs, links, key UI)
Primary dark:       #0F3399   (hover states)
Primary light:      #EBF0FF   (backgrounds, chips)
Secondary:          #00B4D8   (accents, highlights)
Accent / Warning:   #F59E0B
Navy (dark bg):     #0A1628   (headers, footers)

Semantic colours:
  Success  #22C55E  |  Warning  #F59E0B  |  Error  #EF4444  |  Info  #3B82F6

Neutrals (light → dark):
  50  #F9FAFB  |  100  #F3F4F6  |  200  #E5E7EB  |  300  #D1D5DB
  500  #6B7280  |  700  #374151  |  800  #1F2937  |  900  #111827

─── TYPOGRAPHY ────────────────────────────────────────────────
Font family:   Inter (Google Fonts), fallback system-ui, sans-serif
Scale:
  xs  12px  |  sm  14px  |  base  16px  |  lg  18px  |  xl  20px
  2xl 24px  |  3xl 30px  |  4xl  36px

Weights: Light 300, Regular 400, Medium 500, Semibold 600, Bold 700, ExtraBold 800
Line heights: tight 1.25 | snug 1.375 | normal 1.5 | relaxed 1.625

Headings:   Bold or ExtraBold, tight line-height, negative letter-spacing (-0.02em for large)
Body text:  Regular 400, normal line-height (1.5)
Labels:     Semibold 600, sm or xs size
Eyebrows:   Semibold, uppercase, letter-spacing 0.08em, use primary colour

─── SPACING SCALE ─────────────────────────────────────────────
Base unit: 4px
  spacing-1  4px   |  spacing-2  8px   |  spacing-3  12px
  spacing-4  16px  |  spacing-5  20px  |  spacing-6  24px
  spacing-8  32px  |  spacing-10 40px  |  spacing-12 48px  |  spacing-16 64px

─── BORDER RADIUS ─────────────────────────────────────────────
  sm   4px  (subtle: inputs, small chips)
  md   6px  (default: buttons, inputs)
  lg   8px  (panels, dropdowns)
  xl   12px (cards, modals)
  full 9999px (pills, badges, avatars)

─── SHADOWS ───────────────────────────────────────────────────
  sm  0 1px 2px rgba(0,0,0,.06), 0 1px 3px rgba(0,0,0,.08)
  md  0 4px 6px rgba(0,0,0,.07), 0 2px 4px rgba(0,0,0,.06)
  lg  0 10px 15px rgba(0,0,0,.08), 0 4px 6px rgba(0,0,0,.05)

─── COMPONENT RULES ───────────────────────────────────────────
Buttons:
  Primary   – bg #1B4FD8, white text, hover #0F3399
  Secondary – transparent bg, primary border & text, hover primary-light bg
  Ghost     – transparent bg, neutral-300 border, neutral-700 text
  Danger    – bg #EF4444, white text
  Sizes: sm (8/12), md (10/20), lg (12/32) [padding top-bottom / left-right]
  Font: Semibold 600, border-radius: md (6px)
  Always use 2px borders on all button variants for consistency.

Inputs & Forms:
  Border: 1.5px solid neutral-300
  Focus: border primary + box-shadow 0 0 0 3px rgba(27,79,216,.15)
  Error: border #EF4444, show error message in xs red text below
  Labels: Semibold 600, sm size, neutral-700, above the input
  Radius: md (6px)

Cards:
  bg white, border 1px neutral-200, border-radius xl (12px), shadow-md
  Padding: 24px (spacing-6)

Badges / Pills:
  Primary  bg primary-light / text primary
  Success  bg #DCFCE7 / text #15803D
  Warning  bg #FEF3C7 / text #92400E
  Error    bg #FEE2E2 / text #B91C1C
  Neutral  bg neutral-200 / text neutral-700
  Shape: border-radius full (9999px), padding 3px 12px, font-size xs, semibold

Alerts:
  Left border 4px + matching light background tint.
  Always include an icon and a bold title line.

Tables:
  Header: xs, uppercase, semibold, neutral-500, bg neutral-50
  Rows: sm text, neutral-700, 1px neutral-100 dividers
  Hover: bg neutral-50
  Wrap in border 1px neutral-200 + border-radius lg

─── ACCESSIBILITY ─────────────────────────────────────────────
- Minimum contrast ratio 4.5:1 for body text, 3:1 for large text.
- All interactive elements must have visible focus rings (box-shadow preferred).
